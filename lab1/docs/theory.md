# Теоретическая справка

## 1. Машина Тьюринга

Машина Тьюринга (МТ) — формальная модель вычислений, предложенная
Аланом Тьюрингом в 1936 году.

### 1.1. Состав

- **Лента** — бесконечная в обе стороны последовательность ячеек,
  в каждой хранится один символ.
- **Алфавит** — конечное множество допустимых символов. Один из них
  (`blank`, обычно `_`) обозначает пустую ячейку.
- **Головка (каретка)** — указывает на текущую ячейку, умеет читать
  и записывать символ, сдвигаться влево (`L`), вправо (`R`) или
  оставаться на месте (`S`).
- **Состояния** — конечное множество, есть начальное (`q0`) и
  заключительные (`q_accept`, `q_reject`).
- **Программа** — конечный набор правил вида
  `(q, a) → (q', a', d)`, где `q` — текущее состояние, `a` — читаемый
  символ, `q'` — следующее состояние, `a'` — записываемый символ,
  `d` — направление.

### 1.2. Шаг

1. Прочитать символ под головкой.
2. Найти правило для пары `(текущее состояние, символ)`.
3. Если правило не найдено — остановиться.
4. Иначе: записать `a'`, сдвинуть головку в направлении `d`,
   перейти в состояние `q'`.

### 1.3. Остановка

Машина останавливается в двух случаях:

- текущее состояние входит в множество заключительных;
- для пары `(состояние, символ)` нет правила.

### 1.4. Пример: инкремент унарного числа

Вход `111`, головка в позиции 0, состояние `q0`.

Программа:
q0 1 q0 1 R
q0 _ q_accept 1 S

Трассировка:

| Шаг | Состояние | Позиция | Лента |
|---|---|---|---|
| 0 | q0 | 0 | 111_ |
| 1 | q0 | 1 | 111_ |
| 2 | q0 | 2 | 111_ |
| 3 | q0 | 3 | 111_ |
| 4 | q_accept | 3 | 1111 |

## 2. Нормальные алгорифмы Маркова

Нормальные алгорифмы Маркова (НАМ) — формальная модель вычислений,
предложенная Андреем Марковым-младшим в 1947–1951 годах.

### 2.1. Состав

- **Слово** — строка символов, вход и выход.
- **Правила подстановки** — упорядоченный список вида `α → β`
  (обычное) или `α →. β` (заключительное).

### 2.2. Шаг

1. Просмотреть правила сверху вниз.
2. Найти первое, чья левая часть входит в слово.
3. Если не найдено — остановиться.
4. Если найдено обычное правило — заменить **первое** вхождение
   левой части на правую, вернуться к шагу 1.
5. Если найдено заключительное правило — заменить и остановиться.

### 2.3. Пример: сложение унарных чисел

Вход `11+111`.

Правила:
1+ -> +1

    ->.

Трассировка:

| Шаг | Слово |
|---|---|
| 0 | 11+111 |
| 1 | 1+1111 |
| 2 | +11111 |
| 3 | 11111 |

## 3. Эквивалентность моделей

Машина Тьюринга и нормальные алгорифмы Маркова **эквивалентны по
вычислительной мощности**: класс функций, вычислимых на МТ, совпадает
с классом функций, вычислимых НАМ. Это частный случай **тезиса
Чёрча–Тьюринга**: любой алгоритм, вычислимый интуитивно, вычислим на
машине Тьюринга.

### 3.1. Соответствие понятий

| Понятие | МТ | НАМ |
|---|---|---|
| Память | лента | слово |
| Состояние | явное | нет |
| Правило | `(q, a) → (q', a', d)` | `α → β` |
| Стиль | императивный | декларативный |
| Остановка | `q_accept` или нет правила | заключительное правило или нет подходящего |

## 4. Границы вычислимости

Формализация понятия «алгоритм» позволила доказывать неразрешимость.

**Проблема остановки.** Не существует алгоритма, который по описанию
произвольной программы и её входа определяет, остановится программа
или нет.

**Entscheidungsproblem.** Не существует алгоритма, который по
произвольному утверждению формальной системы определяет, доказуемо
оно или нет.

Эти результаты получены Тьюрингом и Чёрчем в 1936 году и опираются
на формальную модель вычислений.
