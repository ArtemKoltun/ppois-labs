# Отчёт по лабораторной работе №1

## 1. Задание

Вариант 1.8 «Абстрактные машины». Реализовать классы, описывающие
абстрактную машину, её ленту, программу и правила, каретку, алфавит,
строку. Минимум три класса.

Выбранные подварианты:

- 1.8.2 — машина Тьюринга;
- 1.8.3 — нормальные алгорифмы Маркова.

## 2. Архитектура

Код разделён на три пакета:

- `common` — общий код: ABC `Readable`/`Writable`, `Alphabet`,
  `MachineStatus`, `MenuResult`, виджеты консольного меню.
- `turing_machine` — домен, I/O и UI машины Тьюринга.
- `markov_algorithms` — домен, I/O и UI нормальных алгорифмов Маркова.

Внутри каждого модуля — три слоя:

- `domain/` — чистые доменные классы без зависимостей от файлов
  и UI;
- `io/` — парсеры и сериализаторы;
- `ui/` — консольные меню.

Домен не знает об I/O и UI, I/O знает о домене, UI знает об обоих.

### 2.1. Машина Тьюринга

Классы домена:

| Класс | Ответственность |
|---|---|
| `Direction` | Направление сдвига каретки |
| `Alphabet` | Множество допустимых символов |
| `AbstractTape` | Интерфейс ленты |
| `UnboundedTape` | Лента, хранящая только непустые ячейки |
| `Head` | Каретка: позиция, перемещение |
| `AbstractRule` | Интерфейс правила |
| `Transition` | Конкретное правило МТ |
| `Program` | Список правил |
| `TuringMachine` | Координатор: шаг и запуск |

### 2.2. Нормальные алгорифмы Маркова

Классы домена:

| Класс | Ответственность |
|---|---|
| `AbstractRule` | Интерфейс правила |
| `Substitution` | Конкретное правило подстановки |
| `Word` | Слово как неизменяемое значение |
| `Program` | Упорядоченный список правил |
| `MarkovAlgorithm` | Координатор |

## 3. Соответствие требованиям

| Требование Lab 1 | Реализация |
|---|---|
| Инкапсуляция | Все поля приватные, доступ через свойства |
| Отделение UI от домена | `domain/`, `io/`, `ui/` — три слоя |
| Конструктор копирования и присваивание | В Python копирование неявное; `__eq__`/`__hash__` переопределены |
| Корректное освобождение ресурсов | Менеджер контекста (`with path.open(...)`) в `io/parser.py` |
| Сравнение на равенство | `__eq__` во всех доменных классах |
| Чтение/запись объекта | `Readable`/`Writable` (ABC) |
| Разделение интерфейса и реализации | `abstract/` подпакеты с ABC, отдельные файлы реализации |
| Документация (Sphinx) | `docs/conf.py`, `docs/api/*.rst` |
| Покрытие > 90% | `pytest --cov=src --cov-fail-under=90` |
| CLI/меню | `main.py` + `ui/menu.py` в каждом модуле |

## 4. Тестирование

Тесты повторяют структуру `src/`:

- `tests/common/` — ABC, enums, UI-виджеты;
- `tests/turing_machine/` — все доменные классы + парсер;
- `tests/markov_algorithms/` — все доменные классы + парсер.

Покрытие — не ниже 90% (`--cov-fail-under=90`).
