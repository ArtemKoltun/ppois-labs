# PPOIS — лабораторные работы

Репозиторий с лабораторными работами по курсу
«Проектирование программного обеспечения интеллектуальных систем».

## Состав

| Папка | Тема |
|---|---|
| [`lab1/`](lab1/) | Основы ООП: абстрактные машины (машина Тьюринга, нормальные алгорифмы Маркова) |

## Как работать с репозиторием

- Каждая лабораторная работа размещается в своей папке верхнего уровня:
  `lab1/`, `lab2/`, `lab3/`, `lab4/`.
- Работа ведётся в отдельных feature-ветках, в `main` изменения попадают
  только через Pull Request после одобрения преподавателем.
- Сообщения коммитов содержательные, на русском или английском языке.
- Артефакты сборки, файлы IDE и кэши не коммитятся — см. `.gitignore`.

## Как запускать

Для каждой лабораторной работы — свой `pyproject.toml`. Пример для `lab1`:

```bash
cd lab1
pip install -e ".[dev]"
pytest                                   # тесты с покрытием
python main.py examples/turing/unary_increment.json
python main.py examples/markov/unary_addition.json
python main.py examples/turing/unary_increment.json -log
